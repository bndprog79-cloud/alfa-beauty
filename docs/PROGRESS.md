## Заметки
(сюда записывать важные решения и найденные проблемы)
- Номер телефона/WhatsApp в docs/data.js (77010000000) — тестовый: кнопки WhatsApp откроют приложение, но такой номер не найдётся. Перед сдачей заменить на настоящий.

- Этап 7, порядок публикации после любого изменения index.html (цены, тексты, тема): node tools/pwa/build-pwa.js → коммит → push. Скрипт меняет CACHE_VERSION в sw.js. Если забыть — новые цены всё равно видны (страница берётся из сети), но иконки/manifest не обновятся. QR пересобирать только при смене адреса сайта: node tools/qr/build-qr.js (первый раз: cd tools; npm install).
