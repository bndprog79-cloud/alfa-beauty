# ТЗ: интерактивный прайс-лист Alfa Beauty-Lab

## 1. Цель
Интерактивный прайс-лист салона красоты для смартфонов вместо скана или PDF. Клиент открывает прайс по ссылке, смотрит категории и услуги, записывается через WhatsApp с готовым текстом.
Это демо-проект, который потом станет шаблоном для других салонов и бизнесов: новый клиент = новые данные + выбор темы.

## 2. Способы открытия (все три обязательны)
1. **Основной — ссылка на GitHub Pages + PWA.** https://bndprog79-cloud.github.io/alfa-beauty/
   После первого открытия прайс сохраняется в телефоне (service worker) и открывается без интернета. Можно добавить на главный экран как приложение.
2. **Автономный — файл index.html.** Открывается двойным кликом на ПК и планшете без интернета. Не зависит от sw.js и manifest.
3. **Страховка — `<noscript>`.** Если файл открыли в просмотрщике без JavaScript: название салона, телефон (ссылка tel:), кнопка «Открыть прайс в браузере» со ссылкой на сайт. Тексты на RU и KK. Оформление в той же теме.

## 3. Структура файлов
```
alfa-beauty/
├─ index.html              ← продукт (всё встроено)
├─ sw.js                   ← service worker (только для сайта)
├─ manifest.webmanifest    ← PWA-манифест
├─ icons/                  ← icon-192.png, icon-512.png, icon-maskable-512.png, apple-touch-icon.png (180)
├─ og-image.png            ← картинка превью ссылки в мессенджерах (1200×630, этап 11)
├─ qr/alfa-beauty-qr.svg   ← QR-код со ссылкой на сайт (для печати)
├─ tools/                  ← скрипты подготовки: шрифт, иконки, QR (в продукт не входят)
├─ docs/TZ.md, docs/data.js, docs/PROGRESS.md
└─ CLAUDE.md
```

## 4. Данные
- Готовые данные — в docs/data.js (объект `priceData`). Тексты и цены не менять.
- Структура: `meta` (версия, дата актуальности), `company` (контакты, часы работы, ссылки), `ui` (все надписи интерфейса на ru/kk), `categories` (категории → items).
- Услуга: `id`, `illustration`, `name {ru,kk}`, `price {amount, from, per}`, `duration` (минуты), `hit`, `desc {ru,kk}`, `includes {ru[],kk[]}`.
- Поля `desc`, `includes`, `duration`, `hit`, `per` (а также `promo`, `variants`, `group`) могут отсутствовать — интерфейс должен выглядеть нормально и без них.
- Количество услуг в категории и минимальная цена «от …» вычисляются кодом.
- Необязательное поле `promo: { amount, until: "ГГГГ-ММ-ДД" }` — акция (этап 10). `amount` — новая цена, старая берётся из `price.amount`; `from` и `per` наследуются от `price`. Акция действует, пока сегодняшняя дата по `company.timezone` (если пояса нет — по устройству) не позже `until`; после — автоматически обычная цена, без меток. Если `amount` не меньше обычной цены или дата записана не в формате ГГГГ-ММ-ДД — акция не показывается. Процент скидки (округляется до целого) и выгода вычисляются кодом. «от …» в шапке категории считается с учётом действующих акций.
- Необязательное поле `variants: [{ id, name: {ru, kk}, amount }]` — варианты цены (этап 12), например по длине волос. В списке категории и в поиске цена «от <минимальный вариант>» (`price.from` не нужен, `price.per` наследуется); «от …» в шапке категории учитывает минимальный вариант. `price.amount` остаётся запасным значением. `promo` и `variants` в одной услуге не поддерживаются: действует только `variants`, в консоль — предупреждение.
- Необязательное поле `group: {ru, kk}` — раздел внутри категории (этап 12). Подряд идущие услуги с одинаковым `group` показываются в списке категории под общим заголовком; услуги без `group` — без заголовка. В поиске заголовков разделов нет.
- Тексты вариантов в `ui`: `variantsTitle`, `chooseVariant`, `waTemplateVariant` ({name}, {variant}, {price}).
- `meta.share` — тексты превью ссылки (этап 11): `title`, `description` (теги Open Graph и `<meta name="description">`), `tagline` и `heading` (надписи на картинке og-image.png; `heading` — массив строк, каждая крупно отдельной строкой), `cta` (на картинке не показывается — его повторяет описание под картинкой), `locale` (og:locale). Интерфейс прайса их не показывает.
- Тексты акций в `ui`: `promo`, `promosTitle`, `promoUntil` ({date} = ДД.ММ), `promoSave` ({sum}), `oldPrice`, `waTemplatePromo`.

### Форматирование
- Цена: пробел между тысячами (неразрывный), знак ₸. `from: true` → ru «от 20 000 ₸», kk «20 000 ₸ бастап». `per` → « / ноготь» (kk « / тырнақ»).
- Длительность: ru «≈ 40 мин», «≈ 1 ч 30 мин», «≈ 3 ч»; kk «≈ 40 мин», «≈ 1 сағ 30 мин», «≈ 3 сағ».
- Количество услуг: ru «1 услуга / 2 услуги / 5 услуг» (правильное склонение, включая 11–14 и 21, 22…); kk «5 қызмет».

## 5. Экраны и навигация
SPA из трёх экранов в одном файле. Контейнер максимум 480px, по центру на ПК; на широком экране вокруг — фон темы.

**Экран 1. Главная**
- Шапка: монограмма-логотип (SVG, «AB»), название, подзаголовок, адрес с иконкой, статус работы («● Открыто до 20:00» / «Закрыто · откроется в 10:00»), переключатель языка RU | KZ.
- Три круглые кнопки: WhatsApp, Позвонить (tel:), Маршрут (ссылка на 2ГИС, новая вкладка).
- Поле поиска услуг.
- Сетка категорий 2 колонки: базовая иллюстрация категории, название, количество услуг.
- Подвал: дисклеймер, «Цены актуальны на: дата», Instagram, копирайт © год + название.

**Экран 2. Категория**
- Кнопка «‹ Категории».
- Шапка: крупная базовая иллюстрация категории, название, «от X ₸».
- Список услуг: слева мини-иллюстрация услуги (48px), название, длительность, метка «Хит»; справа цена; стрелка ›.

**Экран 3. Услуга**
- Кнопка «‹ [название категории]».
- Крупная иллюстрация услуги вверху (во всю ширину карточки, с мягким фоном).
- Название (шрифт заголовков), крупная цена, длительность, метка «Хит».
- Описание, блок «Что входит» со списком с галочками.
- Кнопка «Записаться через WhatsApp» закреплена внизу экрана (sticky), с учётом safe-area.

**Навигация (hash-маршруты, работают и на file://)**
- `#/` — главная, `#/c/<catId>` — категория, `#/s/<catId>/<itemId>` — услуга.
- Системная кнопка «Назад» Android и свайп iOS возвращают на предыдущий экран (через history, не закрывают прайс).
- Прямой переход по ссылке на услугу работает. Неизвестный адрес → главная.
- При переходе назад восстанавливается позиция прокрутки предыдущего экрана; при переходе вперёд — прокрутка вверх.
- Заголовок вкладки (document.title) меняется по экрану.

Премиальный минимализм для бьюти-сферы: тёплый молочный фон, пудрово-розовый акцент, шоколадный текст, тонкие золотистые линии. Много воздуха, мягкие скругления, никаких резких теней и скачков интерфейса.

### Типографика
- Заголовки: шрифт с засечками, лицензия OFL (Cormorant Garamond или Lora — выбрать тот, что содержит все казахские буквы ә ғ қ ң ө ұ ү һ і Ә Ғ Қ Ң Ө Ұ Ү Һ І). Подмножество: латиница, кириллица, казахские буквы, цифры, ₸, знаки препинания. Формат woff2, base64 внутри index.html, размер до 80 КБ. `font-display: swap`. Подготовка — скриптом в tools/ (fonttools/pyftsubset), исходник шрифта скачать из репозитория google/fonts на GitHub.
- Основной текст: системный шрифт (`system-ui, -apple-system, "Segoe UI", Roboto, sans-serif`).
- Размеры: название салона 30px, заголовок экрана 26px, название услуги в карточке 26px, цена в карточке 30px, текст 16px, мелкий текст 13px. Минимум 12px.

### Компоненты
- Карточки категорий: фон --surface, радиус --radius, тонкая рамка --line, иллюстрация сверху на фоне --surface-2, при нажатии — scale(.97).
- Строки услуг: высота от 64px, разделители --line, вся строка — зона нажатия.
- Метка «Хит»: маленькая пилюля, фон --surface-2, текст --accent-strong.
- Кнопки быстрых действий: круг 52px с иконкой и подписью под ним.
- Главная кнопка записи: фон --accent-strong, текст --on-accent, высота 56px, радиус 16px, иконка WhatsApp слева.
- Тонкие золотистые линии (--gold, 1px) — разделители секций в шапке и подвале.
- Декор шапки: тонкие ботанические веточки SVG по краям, полупрозрачные.
- Все зоны нажатия не меньше 44×44px. Видимый фокус для клавиатуры.

### Анимации
- Переход между экранами: вперёд — новый экран въезжает справа (translateX 24px → 0 + opacity), назад — наоборот; 300 мс, ease-out. Без мерцания и «прыжков» высоты.
- Карточки категорий и строки услуг появляются по очереди (задержка 30–40 мс).
- Иллюстрация в карточке услуги «прорисовывается» линиями (stroke-dasharray с pathLength="1"), 900 мс, затем мягко проявляется заливка.
- `prefers-reduced-motion: reduce` — без сдвигов и прорисовки, только мгновенная смена.

### Адаптивность
- viewport-fit=cover, отступы safe-area (env(safe-area-inset-*)).
- Ширина 320–480px — основной сценарий; на планшете и ПК контейнер 480px по центру.
- Горизонтальная ориентация телефона не ломает вёрстку.

## 7. Иллюстрации
- Рисуются SVG-кодом вручную, в едином стиле: тонкие линии (stroke-width 1.6, round caps/joins), мягкие заливки, минимум деталей, элегантность.
- Цвета только через переменные: линии `var(--accent-strong)`, заливки `var(--ill-fill)`, акценты `var(--gold)` и `var(--accent)`. При смене темы иллюстрации перекрашиваются сами.
- Хранятся в объекте `ILLUSTRATIONS` (ключ → SVG-разметка), viewBox 0 0 200 140. Одна и та же иллюстрация используется крупно (карточка услуги, шапка категории), средне (плитка) и мини (48px в списке) — на мини-размере должна оставаться читаемой.

## 8. Функции
- **Язык.** RU по умолчанию, KZ по кнопке. Выбор запоминается (localStorage, try/catch). Меняются все тексты, включая формат цен, длительностей, статуса, текста WhatsApp и `<html lang>`.
- **Поиск.** По названиям и описаниям услуг текущего языка, без учёта регистра, ё=е. Результаты появляются под полем вместо сетки категорий (мини-иллюстрация, название, категория, цена); нажатие → карточка услуги. Крестик очищает поиск. Нет результатов → «Ничего не найдено».
- **Статус работы.** По `company.hours` и времени устройства: «Открыто до 20:00» или «Закрыто · откроется в 10:00». Обновляется раз в минуту.
- **WhatsApp.** `https://wa.me/<номер>?text=<encodeURIComponent(шаблон)>`. Шаблон из `ui.waTemplate` с подстановкой {name} и {price}. Кнопка в шапке — `ui.waGreeting` без услуги.
- **Акции.** Главная, под поиском: блок «Акции» — горизонтальная лента карточек (рисунок, название, новая цена, зачёркнутая старая, «−N%»), прокручивается только лента; нет действующих акций — блока нет. Плитка категории — метка «Акция». Строка услуги — новая цена акцентом, под ней `<del>` со старой (aria-label из `oldPrice`), пилюля «−N%». Карточка услуги — крупная новая цена, зачёркнутая старая, «Акция до ДД.ММ», «Выгода X ₸». WhatsApp — шаблон `waTemplatePromo` с новой ценой. Окончание акции проверяется при открытии, раз в минуту и при возврате во вкладку. Цвета — только переменные темы, контраст AA.
- **Варианты цены.** В карточке услуги с `variants` под ценой — блок `variantsTitle` с подсказкой `chooseVariant`: таблица «название — цена» с радиокнопками (родные `input type="radio"` в `fieldset`/`legend`, строка ≥ 44px, клавиатура: Tab, стрелки, пробел). По умолчанию ничего не выбрано, крупная цена — «от <минимальный>», WhatsApp — обычный `waTemplate`. При выборе без перерисовки экрана крупная цена меняется на цену варианта, кнопка записи — на шаблон `waTemplateVariant`. Выбор хранится в памяти страницы (сохраняется при смене языка и «Назад», после перезагрузки сброшен).
- **Разделы.** Список категории с полями `group` делится на подсписки с заголовками разделов; категория без `group` — один список, как раньше.
- **Звонок.** `tel:+<номер>`.
- **Маршрут, Instagram.** Ссылки из `company`, открываются в новой вкладке (`rel="noopener"`).

## 9. PWA и публикация
- manifest.webmanifest: name, short_name «Alfa Beauty», start_url «./», display standalone, theme_color и background_color из темы, иконки.
- Иконки PNG генерируются скриптом из SVG-логотипа (tools/).
- sw.js: кэширует index.html, manifest, иконки. Стратегия для страницы — «сначала сеть с таймаутом 3 с»: запрос с `cache: 'no-cache'` (браузер перепроверяет файл у сервера), успешный ответ кладётся в кэш; нет ответа за 3 с или нет сети — сохранённая копия (`caches.match` с `ignoreSearch: true`, чтобы ссылки с ?fbclid=… тоже открывались, запасной вариант `./`). Manifest и иконки — сначала из кэша. Версия кэша в константе CACHE_VERSION (хеш файлов, ставит tools/pwa/build-pwa.js); при изменении версии старый кэш удаляется. (Решение владельца на этапе 7 вместо stale-while-revalidate — чтобы новые цены были видны с первого открытия.)
- В index.html: `<link rel="manifest">`, apple-touch-icon, регистрация sw.js только на http/https.
- QR-код qr/alfa-beauty-qr.svg со ссылкой на сайт, тёмные модули цвета --text темы nude, уровень коррекции M, генерация скриптом (npm-пакет qrcode в tools/).
- Превью ссылки (Open Graph, этап 11): og-image.png 1200×630 до 300 КБ — логотип, название, `meta.share.tagline` и строки `meta.share.heading` — крупно (в WhatsApp картинка уменьшается примерно в 4 раза; длинные надписи уменьшаются автоматически), рисунки hair-base, nails-base, lashes-base в цветах темы; всё важное в центральном квадрате 630×630. Плашки «Акции» на картинке нет: мессенджеры долго хранят превью. В `<head>` между метками `<!--OG:START-->`…`<!--OG:END-->`: description, og:type/site_name/title/description/url/locale, og:image (абсолютный адрес от `meta.siteUrl` с `?v=<хеш картинки>`), og:image:type/width/height/alt, twitter:card summary_large_image. Картинку и теги собирает tools/pwa/build-pwa.js; в кэш sw.js картинка не входит.
- Публикация: GitHub Pages, ветка main, корень.

## 10. Критерии приёмки (общие)
1. index.html открывается двойным кликом без интернета; все экраны работают.
2. Сайт на GitHub Pages открывается на Android (Chrome) и iPhone (Safari) по ссылке из WhatsApp и Telegram.
3. После первого открытия сайт работает в режиме «в самолёте».
4. Кнопка «Назад» Android возвращает на предыдущий экран, а не закрывает прайс.
5. Кнопка записи открывает WhatsApp с правильным текстом на выбранном языке (кириллица, кавычки «», знак / не ломают ссылку).
6. Все 6 категорий и 29 услуг отображаются, количество и «от …» посчитаны верно.
7. Переключение RU/KZ меняет все тексты; выбор сохраняется после перезапуска.
8. Поиск находит «педикюр», «ресниц», «омбре»; «шаш» на KZ.
9. Смена `meta.theme` на noir и sage перекрашивает всё, включая иллюстрации.
10. Нет горизонтальной прокрутки на ширине 320px; нет ошибок в консоли.
11. При отключённых анимациях (reduced motion) всё работает без движения.
12. Без JavaScript показывается блок noscript с телефоном и ссылкой.
13. Размер index.html до 400 КБ.
