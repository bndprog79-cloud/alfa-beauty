# Иллюстрации

Рисунки прайса описаны кодом в `build-illustrations.js`. Скрипт собирает SVG-строки и вставляет
объект `ILLUSTRATIONS` в index.html между метками `/*ILL:START*/ … /*ILL:END*/`.
Править рисунки — только здесь, потом запускать скрипт (ручные правки в index.html перезапишутся).

Запуск из папки проекта (PowerShell):

```
node tools/illustrations/build-illustrations.js
node tools/preview/build-gallery.js
```

Второй скрипт собирает `tools/preview/gallery.html` (в git не попадает): «в контексте» (главная,
экраны категорий, карточка услуги), затем все рисунки в трёх размерах — в темах nude, noir, sage.
Открыть двойным кликом. Можно ограничить: `node tools/preview/build-gallery.js nails,feet noir`.

## Цветной стиль «Яркий» (выбран владельцем на этапе 4)
Современная плоская иллюстрация: светлые тёплые цвета, крупные цветные заливки,
тонкий контур (0.6 от обычной толщины), золотые искорки.

### Палитра — CSS-переменные в каждой теме index.html
| Переменная | Что красит | nude | noir | sage |
|---|---|---|---|---|
| --ill-bg | круг-подложка | #FBDCD2 | #3E2D30 | #D2E8CF |
| --ill-hair-dark | тёмные волосы, тень пряди | #9A5A3E | #B06A45 | #985A3F |
| --ill-hair-mid | карамель, основной тон | #E39A62 | #F0A468 | #E09A63 |
| --ill-hair-light | блонд, блики | #FBD58E | #FFDD96 | #F8D48D |
| --ill-skin | кожа (лицо, шея, руки, стопы) | #F8CDB2 | #F6C9AA | #F7CCB1 |
| --ill-berry | ягодный акцент: инструменты, лак, помада, цветы | #EC5B84 | #FF6F98 | #E8587F |
| --ill-gold | золото: искорки, обоймы кистей, стразы | #F4B840 | #FFC64F | #EFB43D |

Цвет волос и кожи во всех темах «настоящий»; от темы зависят подложка и контур.
Если нужен новый цвет — добавить переменную `--ill-…` во все три темы и класс в CSS, не писать цвет в рисунок.

### Классы
- Заливки: `c-bg` подложка, `c-hd` / `c-hm` / `c-hl` волосы тёмные / средние / светлые, `c-sk` кожа,
  `c-be` ягодный, `c-go` золото, `c-mt` металл, `c-aq` мятный, `c-ik` ресницы и подводка.
- Линии: `lc` тонкий контур, `lh` светлые пряди внутри волос, `lo` золотая линия.
- Обычно фигура = `lc` + заливка: `P('lc c-be', …)`. Тень, блик, второстепенные детали — заливка без контура.
- Логотип остаётся в стиле темы (`lg`, `la`, `fl`, `fs`, `fg`, `fw` — цвета --gold, --accent и т. п.).

### Как рисовать (этап 5 — так же)
- viewBox `0 0 200 140`, рисунок в зоне x 44–156, y 16–124 на общей подложке `BG`
  (в 48px видна только середина x 30–170).
- Единый визуальный вес: похожий размер, 1 главный предмет + 1 инструмент/деталь, 2 золотые искорки (`glow`).
- Волосы — с объёмом: основной цвет + тень `c-hd` с одного края + светлый блик (`hairStrand`, `streak`).
- Плавные переходы цвета — стопкой полупрозрачных полос (`stack`, `stackDown`), не градиентом.
- Люди: силуэт одной тонкой линией, кожа `c-sk`, без глаз, носа, губ в деталях.
- Ягодный — главный яркий акцент; не больше 1–2 крупных ягодных пятен на рисунок.
- В noir контур светлый: тёмные мелкие детали делать заливкой, а не линией.

## Технические правила
- Цвета только классами, классы красятся через `var(--...)`.
  Оттенки — прозрачностью (`op` → fill-opacity, `o` → opacity) и наложением фигур.
- Никаких `id`, градиентов, масок и clipPath: одна иллюстрация встречается на странице несколько раз,
  повтор id ломает заливку в Safari.
- Каждая обводка — `<path pathLength="1">` (это делает функция `P`), иначе не сработает анимация прорисовки.
- Скрипт сам проверяет, что в рисунках нет цветов (#…, rgb) и id.

## Готовые картинки (растровые иллюстрации)
Группа «Уход за ногами» (feet-*) — не SVG, а готовое изображение (сделано нейросетью, права на использование есть).
- Файлы лежат в `assets/`: `assets/<ключ>.png`, например `assets/feet-coat.png`.
  Если у ключа нет своего файла, берётся общий `assets/feet-gel.png`. Какие ключи растровые — объект `RASTER` в скрипте.
- Скрипт сборки переводит PNG в WebP через ffmpeg (ширина 480 px, качество 80; если файл больше 40 КБ — качество
  снижается до 50, с предупреждением) и встраивает в index.html как `data:image/webp;base64` — без запросов в сеть,
  работает и при открытии файла двойным кликом. Одинаковая картинка встраивается один раз (`ILL_IMG`).
- Показ: картинка заполняет рамку (`object-fit: cover`), углы — как у рамки. В 48px — квадрат из середины;
  если нужная часть не в центре, поменять `focus` у ключа в `RASTER` (например `'40% 70%'`).
- В карточке услуги вместо прорисовки — мягкое проявление; при reduced motion — сразу.
- Нет файла — у ключа остаётся заглушка, скрипт пишет предупреждение.
- Для проверки на другой папке: `$env:ILL_ASSETS = 'путь'; node tools/illustrations/build-illustrations.js`.
