# Alfa Beauty-Lab — интерактивный прайс-лист

## Кто работает с проектом
Владелец проекта — не профессиональный программист. Общайся на русском языке, простыми словами.
Если что-то нужно сделать вручную (в браузере, на GitHub, на телефоне), давай пошаговую инструкцию: куда нажать и что ввести.
Компьютер: Windows 10, терминал PowerShell в VS Code. Все команды пиши для PowerShell, не для bash.
Папка проекта: C:\Projects\alfa-beauty

## Главные документы
- docs/TZ.md — техническое задание: что и как делать, этапы и критерии приёмки.
- docs/data.js — все данные прайса (тексты RU/KK, цены, длительности). Это источник истины.
- docs/PROGRESS.md — отметки о выполненных этапах и следующий шаг.

Перед любой работой прочитай эти три файла.

## Порядок работы
1. Один запуск = один этап из docs/TZ.md. Не выходи за рамки этапа и не делай работу следующих этапов.
2. Сначала покажи план этапа (какие файлы создашь или изменишь, что проверишь) и дождись подтверждения.
3. В конце этапа:
   - проверь результат по критериям этапа из docs/TZ.md и коротко отчитайся по каждому пункту;
   - обнови docs/PROGRESS.md (что сделано, следующий этап);
   - сделай `git add -A` и `git commit -m "Этап N: краткое описание"`;
   - если remote настроен, сделай `git push`.
4. После обрыва связи: проверь `git status` и docs/PROGRESS.md, продолжи с места остановки, не переделывая готовое.
5. Не удаляй и не переименовывай файлы в docs/ без прямой просьбы.

## Технические правила
- Продукт — один файл index.html в корне. Весь HTML, CSS, JS, SVG и шрифт встроены в него.
- Без фреймворков и библиотек. Без внешних ресурсов: никаких CDN, Google Fonts, картинок по URL, запросов в сеть.
- Обычный JavaScript (ES2017), без сборщика. index.html должен работать при открытии двойным кликом (file://).
- Вспомогательные скрипты (подготовка шрифта, генерация QR и иконок) — в папке tools/ на Node.js. В продукт они не входят.
- Данные — только в объекте `priceData` в начале скрипта index.html. Он копируется из docs/data.js без изменения текстов и цен.
  Если данные в docs/data.js изменились, переносить их в index.html целиком.
- Все надписи интерфейса берутся из `priceData.ui`. Никакого текста, «зашитого» в код.
- Все цвета — только через CSS-переменные темы. Никаких цветов в коде иллюстраций, кроме var(--...).
- Данные в DOM вставлять через textContent / createElement или с экранированием. Не вставлять данные в innerHTML без экранирования.
- localStorage — только внутри try/catch. Если хранилище недоступно, всё работает с настройками по умолчанию.
- Service worker регистрировать только если location.protocol — http: или https:.
- Поддержка браузеров: Chrome (Android, ПК), Safari (iOS 15+), Samsung Internet, Edge, Firefox.
- Размер index.html: цель до 300 КБ, предел 400 КБ.
